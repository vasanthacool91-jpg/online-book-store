# 📚 Online Book Store

A full-stack **Online Book Store** application built using **Next.js** for the frontend and **FastAPI** for the backend. The project demonstrates modern web development practices, including authentication, shopping cart, wishlist management, and order processing.

---

## 🚀 Tech Stack

### Frontend

* Next.js
* React
* TypeScript
* Tailwind CSS
* Axios

### Backend

* FastAPI
* SQLAlchemy
* MySQL
* JWT Authentication
* Pydantic

### Tools

* Git & GitHub
* REST API
* Postman

## ⚙️ Backend Setup

```bash
cd backend

python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```

Backend runs at:

```
http://localhost:8000
```

Swagger API:

```
http://localhost:8000/docs
```

---

## 💻 Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Frontend runs at:

```
http://localhost:3000
```
